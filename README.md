# 💰 Expense Tracker (Python + Tkinter + SQLite)

A simple **desktop application** to manage your expenses, built with **Python, Tkinter, SQLite, and Matplotlib**.

---

## ✨ Features
- Add expenses with **category, amount, and date**  
- View all expenses in a **table view**  
- Category-wise **summary of spending**  
- **Pie chart visualization** using Matplotlib  
- Data stored locally using **SQLite database**  

---

## 📂 Project Structure

ExpenseTracker/
│── expense_tracker_gui.py # Main Python script
│── requirements.txt # Required dependencies
│── README.md # Project documentation
│── expenses.db # SQLite database (auto-created on first run)
